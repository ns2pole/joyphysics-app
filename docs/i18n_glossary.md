## Style notes

- Prefer `\frac{a}{b}` (not `a/b`, not `\dfrac` / `\tfrac`) in display math.
- Inline math that includes fractions/sums/roots should use `\displaystyle`.
- Keep HTML structure (`<div class="common-box">`, `<p>`, lists) when translating.
